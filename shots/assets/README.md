# Pictures of the screenshots

The pictures that [`make.ts`](../make.ts) puts into the demo were generated with Qwen-Image 2.1 through ComfyUI from the
project owner's prompts, then downscaled and optimized. The people shown are fictitious; any resemblance to real persons
is coincidental. Like the screenshots, these files are licensed under CC-BY-4.0; they are not part of the tavrn
trademark.
